# Code of conduct

Everyone should be able to learn here without harassment. Be respectful, assume different levels of experience, and criticize ideas and code rather than people. Give beginners specific, patient feedback. Respect privacy and never publish another person's private information.

Harassment, threats, discriminatory remarks, sexualized content directed at participants, and repeated disruption are unacceptable in issues, pull requests, discussions and other project spaces.

Report concerns privately to the repository owner through an available private GitHub channel. Include relevant links and context; do not repost harmful private material publicly. Maintainers will review reports confidentially to the extent practical, disclose conflicts of interest, and respond proportionately. Responses may include a request to stop, content removal, a temporary restriction, or removal from project spaces. Participants may request reconsideration with new context.

Maintainers follow the same standards. This policy applies to project interactions and to representing the project elsewhere.
