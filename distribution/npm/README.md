# Lumen notes course package

Synthetic in-memory notes over stdio; new notes disappear when the server exits.
`lumen-notes` starts a read-only server. Set `LUMEN_NOTES_READ_ONLY=false` to expose
create/tag tools, which require explicit confirmation. Node 24 or 26 is required.
The bundle contains its dependencies and reads no course files. This package has
not been published to npm. Choose a scope you own before publishing your copy.
