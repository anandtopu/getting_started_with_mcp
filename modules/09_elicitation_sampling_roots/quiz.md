# Module 09 quiz

1. Who supplies a form answer?

<details><summary>Answer</summary>

The host obtains it from the user, outside the model-controlled tool arguments.

</details>

2. Why bind arguments?

<details><summary>Answer</summary>

A confirmation for one issue list must not authorize another.

</details>

3. Why use strict booleans?

<details><summary>Answer</summary>

Strings such as true or yes are not the requested JSON boolean.

</details>

4. Does accepting URL mode complete consent?

<details><summary>Answer</summary>

No. The server must verify the out-of-band outcome.

</details>

5. What does cancel mean?

<details><summary>Answer</summary>

The user dismissed the interaction; the operation does not proceed.

</details>

6. What replaces protocol roots here?

<details><summary>Answer</summary>

A host-configured directory plus canonical path checks and deployment isolation.

</details>

7. What replaces protocol sampling here?

<details><summary>Answer</summary>

A direct provider call controlled by the application and approved before sending file content.

</details>
