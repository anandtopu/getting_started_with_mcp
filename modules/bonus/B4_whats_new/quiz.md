# Quiz

1. What does a successful schema validation prove?

<details><summary>Answer</summary>

Shape constraints only; it does not grant permission or establish endpoint trust.

</details>

2. Why include the server in skill identity?

<details><summary>Answer</summary>

Two servers can advertise the same URI or name. Cache and approval must stay partitioned.

</details>

3. Can a resource read activate instructions?

<details><summary>Answer</summary>

No. Activation is a separate host policy decision.

</details>

4. Does every official SDK implement the newest revision?

<details><summary>Answer</summary>

No. Inspect its release, feature matrix and an actual captured exchange.

</details>

5. Why keep tests synthetic?

<details><summary>Answer</summary>

They reproduce failures without contacting accounts or exposing real data.

</details>

6. What must accompany a useful issue report?

<details><summary>Answer</summary>

Exact versions, a minimal reproduction, expected and observed outcomes, and redacted evidence.

</details>
