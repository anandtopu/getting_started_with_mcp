# Module 08 quiz

1. Why does the database belong to lifespan?

<details><summary>Answer</summary>

It has explicit startup and cleanup ownership rather than opening an unbounded connection per tool.

</details>

2. What makes cancellation cooperative?

<details><summary>Answer</summary>

The task reaches awaited work where cancellation can be delivered.

</details>

3. Does a progress notification complete a tool?

<details><summary>Answer</summary>

No. The matching final response completes the request.

</details>

4. Where do logs go?

<details><summary>Answer</summary>

Application diagnostics go to stderr; they must not corrupt stdio JSON messages.

</details>

5. Can an empty page have a successor?

<details><summary>Answer</summary>

Yes. The cursor is the authority.

</details>

6. Does the quarter label filter fixture dates?

<details><summary>Answer</summary>

No. This report deliberately simulates sections and summarizes all issues.

</details>
