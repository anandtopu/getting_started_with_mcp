# Capstone projects

Each project has a runnable conservative starter, reference solution, acceptance tests, policy evaluation, filled security checklist and rubric. Run `uv run python scripts/capstones.py` for the five finite reference scenarios.

- [01 personal knowledge](01_personal_knowledge/README.md)
- [02 security audit](02_security_audit/README.md)
- [03 lumen gateway](03_lumen_gateway/README.md)
- [04 lumen ops](04_lumen_ops/README.md)
- [05 lumen chat pro](05_lumen_chat_pro/README.md)

The 80/100 rubric threshold never excuses an unapproved mutation, credential disclosure or escaping the allowed data boundary.
