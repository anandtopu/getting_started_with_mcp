# Self-grading rubric

| Criterion | Points | Evidence |
|---|---:|---|
| User stories | 25 | Demonstrate every acceptance criterion |
| Protocol | 20 | Explain captured requests, responses and capabilities |
| Security | 25 | Denied cases, exact approval and no secret disclosure |
| Tests | 20 | Independent expected outcomes and failure regressions |
| Teaching and operations | 10 | Reproducible commands, limits and teardown |

80/100 passes only if security has at least 20/25. A credential leak, arbitrary command execution, unbounded file access or unapproved mutation fails regardless of total score. Explain each deduction in your submission.
